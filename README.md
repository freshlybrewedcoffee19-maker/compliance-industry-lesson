# Security compliance in India: beginner lesson

Interactive lesson with four animations, a three-question quiz, linked original sources, and a reference guide covering six questions about the compliance industry.

Sources and pricing were reviewed on 23 November 2026. Vendor price examples are not market averages. This is educational material; applicability depends on the organisation and assessment scope.

## Files

- `index.html`: self-contained lesson.
- `reference-guide.html`: standalone six-question reference guide.
- `.nojekyll`: serves the files directly through GitHub Pages.

No backend, sign-in, API keys or paid services are required. The question button copies a prompt to paste into your own AI chat. Learner progress is stored only in their browser. No local lesson library, private notes or account data are published.
